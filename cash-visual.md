
# 🎯 Skill: VF-Banner Generator (Canva)

## Objective

Automatically generate high-quality banner designs in Canva using predefined sizes, Vodafone-aligned styling, and structured layout rules.

---

## 📐 Banner Types & Sizes

### 1. Thin Banner

* **Size:** 375 × 110 px
* **Usage:** Notifications, quick promos, top strips
* **Layout Behavior:**

  * Horizontal layout (wide & short)
  * Prioritize **headline + small icon**
  * Minimal text (max 1–2 lines)

---

### 2. Cash Banner

* **Size:** 242 × 172 px
* **Usage:** Vodafone Cash offers, financial actions
* **Layout Behavior:**

  * Balanced rectangular layout
  * Space for **headline + subtext + CTA**
  * Optional illustration (wallet / money / icon)

---

### 3. VOV Banner

* **Size:** 343 × 153 px
* **Usage:** Vodafone Offers & Value (VOV campaigns)
* **Layout Behavior:**

  * Promotional layout
  * Strong visual hierarchy:

    * Headline (primary)
    * Offer highlight (price / benefit)
    * CTA

---

2. **Check Cash Visuals File**

   * Understand:

   * **System-compliant**
   * **Visually consistent with existing banners**

---

## 🧱 Layout System

* Apply structured layout rules:

  * Padding: **12–16px**
  * Element spacing: **8–12px**
  * Alignment: left or center only

* Safe Area:

  * Minimum margin: **8–12px from edges**

---

## ⚙️ Generation Logic

When creating a banner:

1. Select banner type (Thin / Cash / VOV)
2. Apply correct **frame size**
3. Pull:

   * Colors from **Design System Tokens**
   * Typography from **Text Styles**
   * Logo from **Design System**
4. Review both Figma references
5. Generate:

   * Headline (clear, benefit-driven)
   * Optional subtext
   * CTA (if needed)
6. Add visual (icon / illustration aligned with system style)
7. Validate:

   * Alignment
   * Spacing
   * Hierarchy
   * Contrast

## ✍️ Content Guidelines
