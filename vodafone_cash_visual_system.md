# Vodafone Cash Visual Design System 2026

## Overview
This skill defines the complete visual design system for Vodafone Cash promotional materials, including banners, block screens, and campaign visuals. Based on the official Vodafone Cash Visuals 2026 design file.

## Banner Sizes & Formats

### 1. **Cash Banner** (242 × 172 px)
- Primary format for Vodafone Cash in-app promotions
- Use for: Financial service offers, money transfer campaigns
- Safe area: 10px margin on all sides (222 × 152 px content area)
- Guide dimensions: 222 × 130 px

### 2. **VOV Banner** (Vodafone Offers & Value) (343 × 153 px)
- For promotional campaigns and value propositions
- Use for: Special offers, partner promotions, campaigns
- Safe area: 10px margin on all sides (323 × 133 px content area)
- Guide dimensions: 323 × 133 px

### 3. **Thin Banner** (375 × 110 px)
- Horizontal banner for notifications and top strips
- Use for: Quick announcements, flash offers, notifications
- Safe area: 10px margin on all sides (354 × 90 px content area)
- Guide dimensions: 354 × 90 px

### 4. **Block Screen** (375 × 812 px)
- Full-screen mobile promotional screens
- Use for: Major campaigns, feature launches, seasonal promotions
- Safe area: 16px horizontal margins, 103px top, 623px height content area
- Guides: iOS Status Bar (33px), Home Indicator (26px at bottom)

## Visual Design Elements

### **Background Treatments**

#### Primary Red Background
- **Base Color**: Vodafone Red (#E30613)
- **Gradient Option**: Diagonal gradient from #E30613 to #C20510
- **Texture Overlay**: Paper texture or subtle grain for depth
- Can include photocopy texture for vintage/authentic feel

#### Dual-Tone Split Backgrounds
- **Top Section**: Light mint/sage green (#C8DDD5 - #D5E8E0)
- **Bottom Section**: Vodafone Red (#E30613)
- **Division**: Diagonal split from top-left to bottom-right
- Creates dynamic, eye-catching composition

#### Background Layers (in order):
1. Base background color/gradient
2. Vector decorative elements (optional)
3. Generative fill or texture
4. Content overlays
5. Grungy paper texture overlay (low opacity)
6. Photocopy texture overlay (low opacity)

### **Visual Assets & Iconography**

#### International Transfer Visuals
- **Main Visual Elements**:
  - World landmarks collage (Statue of Liberty, Big Ben, Eiffel Tower, CN Tower, etc.)
  - Multiple country flags in a horizontal row
  - Mobile phone mockups showing the app
  - Passport/visa stamps aesthetic
  - Travel-themed graphics

#### Key Visual Components:
1. **Flags Row**: Horizontal display of 6-8 country flags
   - Countries: Australia, UAE, UK, USA, Canada, EU
   - Size: Approximately 16px height for Cash Banner
   - Positioned near top of composition

2. **Landmark Imagery**:
   - Grayscale or tinted landmark photos
   - Layered composition creating depth
   - Positioned at bottom or background
   - Creates international/travel context

3. **Mobile Device**:
   - Shows Vodafone Cash app interface
   - Can be angled or straight-on view
   - Positioned prominently in composition
   - Size varies by banner format

### **Typography System**

#### Arabic Text Styling
- **Primary Font**: Arabic-compatible font (e.g., Cairo, Tajawal)
- **Main Headline**: Bold, 42-46px for Block Screen, scaled down proportionally for banners
- **Secondary Text**: Medium weight, 28-36px
- **Supporting Text**: Regular, 24-28px
- **CTA/Fine Print**: 18-22px

#### English Text Styling
- **Primary Font**: Vodafone Regular/Bold
- **Main Headline**: Bold, similar sizing to Arabic
- **Body Text**: Regular weight
- **Alignment**: RTL for Arabic, LTR for English

#### Text Hierarchy for Cash Banner (242 × 172 px):
1. **Main Headline**: 17px height, Arabic
2. **Subheadline**: 19px height, Arabic  
3. **Descriptive Text**: 27px height, Arabic
4. **Flags**: 16px height
5. **Disclaimer/CTA**: 26px height

### **Logo & Branding Elements**

#### Vodafone Cash Logo
- **Position**: Top-left corner (8-13px from edge)
- **Size**: 37 × 16 px for Cash Banner, scale proportionally
- **Color**: White lockup on colored backgrounds
- **Format**: "Vodafone Cash" text lockup or speech bubble icon

#### Vodafone Speech Bubble Icon
- **Position**: Bottom-right corner
- **Size**: 70 × 70 px circle for larger formats
- **Design**: White circle with red speech bubble shape inside
- **Shadow**: Subtle drop shadow for depth

#### Partner Logos
- **Example**: "Taptap Send" or partner service
- **Position**: Integrated into main composition
- **Size**: Proportional to content hierarchy
- **Treatment**: Clean, unobstructed visibility

### **Color Palette**

#### Primary Colors
- **Vodafone Red**: #E30613
- **Vodafone Red Dark**: #C20510
- **White**: #FFFFFF

#### Secondary/Accent Colors
- **Mint/Sage Green**: #C8DDD5 - #D5E8E0 (for background sections)
- **Dark Text**: #000000 or #1A1A1A
- **Red for Text**: #E30613 (use sparingly for emphasis)

#### Background Textures
- **Paper Texture**: Low opacity overlay (10-20%)
- **Grain**: Subtle noise for depth
- **Photocopy Effect**: Vintage texture overlay

### **Layout Principles**

#### Composition Guidelines
1. **Safe Zones**: Always maintain 10px margins minimum
2. **Visual Weight**: Balance text and imagery
3. **Diagonal Flow**: Use diagonal compositions for dynamism
4. **Layering**: Create depth with overlapping elements
5. **Breathing Room**: Don't overcrowd small banners

#### Content Hierarchy (Top to Bottom):
1. Vodafone Cash logo (top-left)
2. Main headline
3. Country flags
4. Supporting text/offer details
5. Visual elements (phones, landmarks)
6. CTA or disclaimer
7. Partner branding (if applicable)

#### Text Placement
- **Arabic Banners**: Right-aligned, RTL flow
- **English Banners**: Left-aligned, LTR flow
- **Mixed Content**: Separate clearly, maintain reading order

### **Responsive Sizing**

#### Banner Size Relationships
- **Thin Banner** (375 × 110): Minimal text, horizontal focus, quick glance
- **Cash Banner** (242 × 172): Balanced composition, medium detail
- **VOV Banner** (343 × 153): Slightly wider than Cash, more horizontal
- **Block Screen** (375 × 812): Full detail, maximum information, immersive

#### Scaling Rules
When adapting designs across formats:
1. **Text Size**: Scale proportionally to banner dimensions
2. **Logo Size**: Maintain minimum legibility (not below 30px width)
3. **Imagery**: Crop intelligently, maintain focal points
4. **Spacing**: Adjust margins proportionally
5. **Hierarchy**: Simplify for smaller formats

### **Technical Specifications**

#### File Format
- **Export Format**: PNG for final assets
- **Color Space**: sRGB
- **Resolution**: 72 DPI (for digital screens)
- **Transparency**: None (solid backgrounds)

#### Design Files
- **Source**: Figma (editable)
- **Components**: Reusable elements for consistency
- **Variants**: Arabic and English versions
- **Naming**: Clear, descriptive layer names

## Design Process Workflow

### 1. **Content Planning**
- Define main message (max 10-15 words for banners)
- Identify target audience
- Choose appropriate banner size
- Determine language (Arabic/English/Both)

### 2. **Visual Direction**
- Select background treatment (solid red, dual-tone, etc.)
- Choose relevant imagery (landmarks, flags, devices)
- Plan compositional layout
- Determine text hierarchy

### 3. **Design Execution**
- Start with safe area guides
- Place background and textures
- Add visual elements (imagery, landmarks)
- Position logos and branding
- Add text in hierarchy order
- Apply textures and overlays
- Final polish and adjustments

### 4. **Quality Checks**
- ✅ Text readability at actual size
- ✅ Logo visibility and clarity
- ✅ Safe area compliance
- ✅ Color accuracy (Vodafone Red)
- ✅ Alignment and spacing consistency
- ✅ File size optimization
- ✅ Cross-device preview

## Common Patterns & Best Practices

### ✅ DO:
- Use official Vodafone red (#E30613)
- Maintain safe areas religiously
- Keep text concise and scannable
- Use high-quality imagery
- Create depth with layering
- Test readability at actual size
- Provide both Arabic and English variants
- Use diagonal compositions for energy
- Include relevant country flags for international themes

### ❌ DON'T:
- Deviate from brand colors
- Overcrowd small banners
- Use low-resolution imagery
- Ignore safe area guides
- Mix too many visual styles
- Use overly complex backgrounds that compete with text
- Forget mobile context (banners viewed on phones)
- Omit Vodafone branding elements
