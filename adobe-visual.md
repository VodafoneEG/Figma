# Skill Name
Adobe Visual Background Removal & Resize

# Skill Purpose
Receive any visual asset, remove its background, and export two centered PNG versions with transparent background while keeping balanced quality.

# Input
- Any image or visual asset uploaded by the user.
- Supported formats: JPG, JPEG, PNG, WEBP, SVG if supported by Adobe tools.

# Output
Create two final PNG files:
1. 600 x 400 px
2. 267 x 191 px

Both outputs must:
- Have transparent background.
- Keep the main visual centered.
- Preserve the original subject quality as much as possible.
- Avoid stretching or distorting the visual.

# Workflow

## 1. Receive and Inspect Visual
- Read the uploaded visual.
- Identify the main subject/object.
- Check visual quality, edges, shadows, and transparency needs.

## 2. Remove Background
- Use Adobe Photoshop or Adobe background removal tool.
- Remove the full background.
- Keep the subject edges clean.
- Preserve natural details such as hair, soft edges, shadows, and product contours.
- Do not crop or cut any part of the main subject.

## 3. Create Transparent Canvas 600 x 400 px
- Create a new canvas sized 600 x 400 px.
- Place the cutout subject in the center.
- Scale proportionally to fit inside the canvas.
- Keep safe spacing around the subject.
- Do not stretch the image.
- Export as PNG with transparent background.

## 4. Create Transparent Canvas 267 x 191 px
- Create a new canvas sized 267 x 191 px.
- Place the cutout subject in the center.
- Scale proportionally to fit inside the canvas.
- Keep safe spacing around the subject.
- Do not stretch the image.
- Export as PNG with transparent background.

## 5. Quality Rules
- Keep the best balance between file size and image quality.
- Avoid pixelation.
- Avoid over compression.
- Preserve sharpness and clean edges.
- Use PNG format only.
- Keep transparency active in both files.

# Final Deliverables
- `visual_600x400_transparent.png`
- `visual_267x191_transparent.png`

# Validation Checklist
Before final delivery, confirm:
- Background is removed.
- Canvas size is exactly 600 x 400 px.
- Canvas size is exactly 267 x 191 px.
- Subject is centered in both outputs.
- PNG transparency is preserved.
- Image quality is balanced and clean.
